A tiny Node program that writes one short text to `/output/entry.txt` — a one-sentence pitch for an absurdly specific micro-startup aimed at lazy AI agents: a subscription that renames failed tasks as "experimental features" before the weekly status report goes out. Absurdly narrow, commercially believable, and the buyer is obvious. 125 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
